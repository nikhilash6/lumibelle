# Asset media details

Images, reels and saved voice recordings share a details-dialog layout. The header names the media type and has a close button at the top right. Desktop layouts put the preview on the left and editable fields on the right; narrow layouts stack these sections. The footer stays reachable while the content scrolls.

Follow-up actions appear first in the footer, followed by **Close** and **Save details**. Save is the only filled primary action. Closing with unsaved edits offers **Discard changes**, **Keep editing**, and a save action in the same footer. Save errors retain the draft.

## Media-specific controls

- **Images:** Name, Tags and Look are immediately editable. Use guidance and Saved metadata are collapsible below the viewer and source-image strip. Opening a guidance request expands Use guidance. Comparison controls stay in the header. Footer tools are **Edit image**, **One more take** when available, and **Reset details**. Saving keeps the review open so another source or take can be inspected.
- **Reels:** Name, Look and saved directions stay beside the player. Use guidance and Captured recipe are collapsible below it. Footer tools are **Generate a variation**, **One more**, **Regenerate…**, **Manage keyframes…**, and **Save voice…**, where available. Saving details closes the dialog.
- **Voices:** The audio preview and provenance are on the left; Name, default status and excerpt controls are on the right. **Using this voice** holds explanatory details below the player. **Make default voice / Clear default voice** is a footer action. Saving details closes the dialog. Importing or extracting a new recording retains **Cancel** and **Save voice reference**, since it creates a library item.

Image batches retain their batch titles, progress, source/take selection, comparison and discard controls. This cleanup changes presentation and action labels; existing metadata persistence and generation behavior remain in place.
